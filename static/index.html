How it works — under the hood

    

      
♪1 · Extract & pitchDemucs isolates vocals → Rubber Band +3 semitones (timing preserved).

      
◐2 · Depth + SAMColored depth (lucataco) → SAM 3 masks → composite over original background.

      
▶3 · Seedance Edit/OmniPrepared video + pitched embed + refs → Enhancor draft. Poll & download.

      
♫4 · Restore audioDiscard AI audio, mux your original soundtrack byte-perfect.

    

    
Local stack: Python 3.12+, FastAPI, PyAV/NumPy/OpenCV/SciPy, local mux. No weights/GPU for hosted mode. Agent skill in .agents/skills/tein-video-workflow can auto-prepare & QA. See docs/MODELS.md · API docs.

FAQ
Honest answers — no hype.

    
How much will a 10s clip cost?
~$0.30 Replicate + ~$1.30 Enhancor draft = ~$1.60. 1080p ~$4.20. Use the calculator above. You pay providers directly — we earn zero on Replicate and a disclosed small referral on Enhancor. Check dashboards for live prices.

    
Do I need a GPU? What do I install?
No GPU. Default setup: Python, Rubber Band CLI, cloudflared (for webhook). Run bash setup.sh → ./start.command → open 127.0.0.1:8770. For mesh modes: bash setup-face-mesh.sh (Python 3.12). Windows → WSL2.

    
Will my audio stay perfect?
Yes. We separate music/vocals only to create a pitch-shifted guide for lip-sync. The final export discards Seedance audio and muxes your original source track byte-for-byte. Verified in tests.

    
Can I use it commercially?
Our code + docs: MIT — yes. You own your exports. You’re responsible for rights to source footage, music and likenesses you supply — just like any editing tool.

    
Is my footage private?
App runs on localhost. Media goes only to Replicate/Enhancor/tmpfiles/catbox via your keys. Runs stay in /runs on your disk. No TEIN account needed. Delete runs to purge.

    
What’s the difference between Fast and Advanced?
Fast overlays a face-mesh on your original video — cheapest, works for 1 centered speaker. Advanced uses colored depth + SAM — any number of people, any framing, most accurate. Advanced+Mesh = both.

    
What if the mask looks wrong?
We block generation until you approve. If depth leaks, use “Repair via RGB” (re-runs SAM on original frames) or switch provider. Never approve a bad mask — you’ll pay for a bad generation. See troubleshooting.
